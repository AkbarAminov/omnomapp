# Переразметка: этап 5 — пары из анализа выбиваний

Правило: трое жителей Ташкента загадали блюдо и отвечают на вопрос. Все «да» → yes, все «нет» → no, иначе any.

Изменено ячеек: 4.

| блюдо | тег (вопрос) | было → стало | почему |
|---|---|---|---|
| Салат Цезарь | `hasCheese` (Сыр — заметная часть?) | yes → **any** | пармезан в Цезаре — одни считают «заметным сыром», другие нет |
| Домашние котлеты с пюре | `isFried` (Хрустящее, с корочкой?) | yes → **any** | жареные котлеты: корочка есть, но «хрустящими» назовут не все |
| Французский хот-дог | `isFried` (Хрустящее, с корочкой?) | no → **any** | хрустящий багет — для части людей «с корочкой» |
| Кесадилья с курицей | `isFatty` (Жирное, на масле?) | yes → **any** | кесадилья с сыром — «жирная» не для всех |

Десертные теги: Тирамису `hasChocolate` yes → **any** — какао сверху, «с шоколадом» ответят не все.
