## Что сделано за итерации

1. **Итерация 1** — два новых различающих вопроса («С курицей?», «Завёрнуто в лаваш или тортилью?»), теги `hasChicken`, `isWrap` у всех блюд (reports/retag_new_tags.md). Фастфуд при p = 0: 74% → 85–86%.
2. **Итерация 2** — анализ пар блюдо×вопрос, которые чаще всего выбивают (`node scripts/knockouts.ts`). Выбивания распределены тонко (2–5 случаев на пару) — это шум, а не систематические ошибки. Исправлены 5 настоящих двусмысленностей (reports/retag_stage5.md).
3. Третья итерация по данным не нужна: оставшиеся промахи не из-за разметки (см. ниже).

## Что не дотянуло и почему

**p = 0 — «Любая кухня» (~70%), перекусы (~65%), «Сладкое» (~80%).** При идеальных ответах загаданное блюдо не попадает в топ-3 из-за **ничьих**: к концу квиза оно стоит вровень с 3+ другими (meal/любая 23%, snack 27%, dessert 10% сессий). 5 ответов на ~100 перекусов и 8 на 228 блюд — не хватает информации, чтобы различить блюда.

**p = 1/7 — все варианты (54–72%).** При 5–8 ответах шанс, что игрок ни разу не ошибся, ≈ 40–50%, а одно расхождение — разрыв в 9 раз (0.9 против 0.1). Смягчение штрафа до 0.2–0.3 почти не помогает (проверено: +0–3 п.п.). Цель 75% недостижима при текущих весах и лимитах.

## Предложения (не применены — нужно ваше решение)

1. **Лимиты ответов** meal/любая 8 → 10, snack 5 → 7, dessert 4 → 6, потолок свайпов 9 → 11. Симуляция:

| вариант | сейчас p=0 / p=1/7 / свайпов | с новыми лимитами |
|---|---|---|
| meal / любая кухня | 69% / 38% / 7.4 | 74% / 41% / 7.9 |
| snack | 61% / 44% / 5.1 | **87%** / 56% / 6.6 |
| dessert | 81% / 61% / 4.1 | **93%** / 63% / 5.3 |

   Перекусы и «Сладкое» проходят цель p = 0 ценой ~1.5 свайпа.
2. **«Любая кухня»** — показать больше вариантов при ничьей (все блюда вровень с 3-м местом, до 5) или задавать сначала «Какая кухня ближе?» — без этого 85% недостижимо.
3. **Веса и порог 15–85%** — менять не рекомендую: смягчение штрафа почти не влияет, а настоящая точность проверяется на живых ответах (этап 9 → `npm run calibrate`).

## После этапа 6 (честный процент, порог 50%)

| вариант | p = 0: база → сейчас | p = 1/7: база → сейчас |
|---|---|---|
| meal / asian | 95% → 98% | 74% → **75%** ✅ |
| meal / central-asia | 95% → 97% | 67% → 70% |
| meal / european | 100% → 97% | 72% → **77%** ✅ |
| meal / middle-east | 100% → 100% | 73% → **80%** ✅ |
| meal / slavic | 91% → 88% | 61% → 61% |
| meal / fast-food | 95% → 88% | 64% → 65% |
| meal / любая кухня | 81% → **52%** | 45% → 33% |
| snack | 64% → **45%** | 45% → 32% |
| dessert | 81% → 85% | 63% → 66% |

Сортировка по честному проценту помогла одиночным кухням (три дошли до цели при p = 1/7), но уронила «Любую кухню» и перекусы. Причина:
при теге any формула даёт загаданному блюду 0.5 за ответ, и его обгоняют блюда с уверенными тегами (100%); плюс правило «одно блюдо на кухню» при ничьей
убирает загаданное блюдо в 42–51% промахов. Варианты решения — в сводке (увеличить лимиты, показывать всю ничью, учитывать any как совпадение в проценте).
